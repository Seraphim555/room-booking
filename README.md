# Бронирование аудиторий

Веб-приложение для расписания аудиторий. На главной видно, свободна комната в текущий слот или занята. У каждой аудитории есть экран с расписанием и панель, где слот можно занять или освободить.

Время считается по Екатеринбургу. Слоты идут с 09:00 до 21:00, каждый по 30 минут. На одно имя можно занять не больше 6 слотов. Записи хранятся в `bookings.json`.

На главной показаны аудитории 101, 102, 103, 201, 202 и 203.

## Страницы

| Адрес | Что открывается |
| --- | --- |
| `/` | Список аудиторий и статус текущего слота |
| `/room/<номер>` | Экран аудитории: время, занятость и слоты |
| `/admin/<номер>` | Панель бронирования |

На панели нужно ввести имя. Повторное нажатие на занятый слот снимает бронь.

## Запуск

Нужен Python 3.9 или новее.

```powershell
pip install -r requirements.txt
python app.py
```

Сервер слушает порт из переменной `PORT`. Если её нет, используется `10000`.

Откройте `http://localhost:10000`.

## Деплой

В репозитории есть `Procfile` и `render.yaml` для запуска на Render: зависимости ставятся из `requirements.txt`, процесс стартует командой `python app.py`.
